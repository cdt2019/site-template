“应该写多少字”是网上被搜索最多的写作问题之一。诚实的答案是：**需要多长就写多长，多一个字都不要。** 不过，确实有一些可供参考的区间。

## 速查表

| 内容类型 | 常见长度 |
| --- | --- |
| 推文 / X 帖子 | 20–40 词 |
| SEO 描述（Meta Description） | 140–160 字符 |
| 产品页面 | 300–800 词 |
| 常规博客 | 1,000–1,500 词 |
| 长篇指南 | 2,500 词以上 |

## 长度服从搜索意图

搜索“PDF 转 Word”的人想要的是工具，而不是文章；搜索“求职信怎么写”的人需要深度内容。先满足搜索意图，字数自然就对了。

> 为读者而写，为编辑而量。

## 用数据来删减，而不是凑字数

1. 写初稿时不要看字数。
2. 把稿子粘贴到统计工具里，查看阅读时长。
3. 删掉所有不值得保留的内容。

<Callout>提示：大多数博客的阅读时长最好控制在 7 分钟以内 —— 超过之后读者流失会明显增加。</Callout>
