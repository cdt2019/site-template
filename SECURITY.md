# Security Policy

## Reporting a vulnerability

**Please don't open a public issue.** Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/cdt2019/site-template/security/advisories/new).

Include the affected file or page, steps to reproduce, and the impact. This is a community project, so response times are best effort. Please allow reasonable time for a fix before disclosing publicly.

## Supported versions

Only the latest commit on `master` receives fixes. If you copied the template, watch this repository and apply security fixes to your site.

## If you deploy this template

- Never commit `.env*` files. Only `.env.example` belongs in the repository.
- Keep `next` up to date.
- If you add a tool that sends user input to a server, update the privacy policy and the "runs in your browser" copy.
